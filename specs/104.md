## 編輯方式

同步腳本用（見 `docs/sync-script.md`）。腳本只在使用者於面板上要求時點「編輯」或「新增」打開表單，見下方「區塊按鈕與清單」。

語文能力、學歷、工作經驗、專長是多筆區塊：一次只能打開一筆編輯；要新增一筆，必須先按該區塊的「新增」，才會出現空白表單。
編輯既有的一筆：滑鼠移到那一筆的卡片上（hover），右上角才會出現編輯按鈕，點下去才會打開該筆的表單。編輯按鈕旁邊就是刪除按鈕，selector 必須用下表的 `data-gtm-cprofile` 精確比對。

### 區塊按鈕與清單

### 清單畫面讀取

沒有打開任何表單時，清單畫面就顯示所有已填的內容，可以一次讀完做全頁比對：

| 欄位 id | 清單畫面 selector | 備註 |
|---|---|---|
| `work.description` | 各 `[data-e2e="experience-list"]` 內的 `pre.experience-list-list__description__inner` | 已確認是全文（字數和編輯表單的計數器一致） |
| `work.name` | 各 `[data-e2e="experience-list"]` 內的 `.experience-list-list__companyName` | 文字是「公司名稱（產業 規模）」，取全形「（」之前；勾選「不顯示公司名稱」時顯示「公司名暫不公開」，要打開表單才看得到 |
| `work.position` | 各 `[data-e2e="experience-list"]` 內的 `.experience-list-list__jobName` | |
| `work.start`、`work.end` | 各 `[data-e2e="experience-list"]` 內 `[data-e2e="experience-list__duration"]` 的第一個 `span` | 格式「2020/3~2021/8」，在職中為「2020/3~仍在職」 |
| `work.skills` | 各 `[data-e2e="experience-list"]` 內文字以 `#` 開頭的 `span.t4` | 一個 span 放全部標籤，例如「#Vue #Git #Git flow」，用 `#` 拆開；標籤本身含 `#`（如 C#）時會拆錯 |

表單列的標題是 `.form-element-form-row__title`（文字含 `*` 子元素），整列是 `.form-element-form-row`。必填檢查訊息在 `.form-element-inputbox__valid`。清單畫面的描述：用 Quill 存過的是 `<p>` 段落（空行為 `<p><br></p>`），舊資料是含換行的純文字。
| `bio.zh` | `[data-e2e="bio-chi"]` | 已確認是全文；「顯示更多」只影響顯示 |
| `bio.en` | `[data-e2e="bio-eng"]` | 同上 |

**不可以點**：所有 `data-gtm-cprofile` 含「刪除」的元素（例如 `edit-工作經歷-刪除`、`edit-學歷-刪除`），以及 `data-e2e="sidebar__item-delete"`。
頁面是 Vue，class 帶 `data-v-*` 屬性，selector 不要用它。
